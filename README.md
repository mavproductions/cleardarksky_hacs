# ClearDarkSky Forecast for Home Assistant 🌌

This custom component integrates the astronomy forecast data from ClearDarkSky into Home Assistant, providing specialized sensors essential for hobby astronomers, stargazers, and anyone interested in local viewing conditions.

# Features ✨

Seeing & Transparency: Tracks and reports the forecast for atmospheric seeing (star twinkling) and sky transparency.

Cloud Cover: Provides hourly forecast data for high, mid, and low-level cloud coverage.

Detailed Conditions: Offers binary sensors for optimal night viewing conditions (e.g., sensor.cleardarksky_is_good_tonight).

Entity Naming: Configurable display names for easy integration into Lovelace dashboards.

## Installation ⬇️

Method 1: Home Assistant Community Store (HACS) (Recommended)

Ensure you have HACS installed and set up in your Home Assistant instance.

In the Home Assistant UI, navigate to HACS -> Integrations.

Click the three dots menu (...) in the top right and select Custom repositories.

Enter the URL of this GitHub repository (https://github.com/YourRepo/cleardarksky-ha) and select the category Integration.

Search for "ClearDarkSky Forecast" in the HACS Integrations section and click Download.

Restart Home Assistant after the download is complete.


## Configuration ⚙️

The integration is configured entirely via the Home Assistant UI.

Go to Settings -> Devices & Services -> Integrations.

Click the Add Integration button (+).

Search for "ClearDarkSky".
